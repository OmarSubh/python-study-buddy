# Install (Claude Desktop) — 5 minutes

## A. The skill (works in every chat)
1. Zip the folder so that SKILL.md is at the top level of the zip (right-click SKILL.md's folder → Compress). Name it python-study-buddy.zip.
2. Claude Desktop → Settings → Capabilities → Skills → Upload skill → choose the zip.
3. Make sure "Skills" is switched on.
4. Test: start a new chat and paste any Python question. Claude should start with "Decode the question".

## B. The Project (keeps your study in one place + memory)
1. Claude Desktop → Projects → New project → name it "Python Study".
2. Open "Set project instructions" → paste the whole text of PROJECT-INSTRUCTIONS.md.
3. Add files: upload study-card.md. Also upload your course slides / lab sheets / past exams if you have them (PDF is fine).
4. Do all your Python chats inside this Project.
5. At the end of a study session, Claude gives you an updated Study Card → open study-card.md, replace its content, re-upload. (One minute, and it is what makes Claude remember your weak spots.)

## Tips
- Paste the exam question exactly as written, including the marks. Trap words matter.
- If you want the answer right away, say "just show me". It will, with the reasoning.
- If an explanation did not land, say "explain it differently". It will use a new example, not the same words.
- Say "quiz me on loops" (or any topic) for 3 practice questions, one at a time.
