# Python Study Buddy

A Claude skill that turns Claude into a patient Python tutor for university students.

It does not just answer. It:
1. **Decodes the question** — rewrites it in plain words, lists Given / Want / Rules, flags trap words, shows one input → output example.
2. **Makes you think first** — asks what you would do before showing anything.
3. **Explains the answer with reasoning** on every line (variable table for "what does this print" questions).
4. **Checks it stuck** with one small follow-up question.
5. **Remembers your weak spots** through a Study Card.

Works in **Arabic or English**. Python terms always stay in English.

## Install
See [INSTALL.md](INSTALL.md). Short version: download this repo as a zip, upload it in Claude Desktop → Settings → Capabilities → Skills, and create a Project with [PROJECT-INSTRUCTIONS.md](PROJECT-INSTRUCTIONS.md).
